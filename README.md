# 不问凡尘 · AI 编辑器 0.3.1

游戏外 Windows 桌面工具。双击 `WorldApart.AI.Editor.exe` 即可使用，不需要 Python、Node.js 或额外 Mod 加载器。

0.3.1 适配游戏 0.35.7370692，加入新模板“本轮关系交互”，补上工坊封面并公开源码。

编辑器提供人物卡片、人物背景与关系态度编辑、23 个全局模板，以及编辑器自己的 JSON 预设。之前保存的超时和说话风格设置会继续使用。隐藏人设、触发条件和特殊指令仍标为实验，实际触发尚未验证。

## 本版功能

- 人物库：1,156 个 NPC 配置，其中 1,084 个有头像映射。头像来自游戏，共用头像仍按称号和配置 ID 区分；缺图时显示姓名首字。每页 12 张卡片，支持搜索和“只看自定义与草稿”。进入编辑后左侧为紧凑头像列表，返回时保留搜索、页码和滚动位置。
- 人物编辑：说话风格、人物背景，以及数据中已有的亲密度 / 道侣态度阶段。支持简体中文、繁体中文和英文、原版对照、撤销此项修改和恢复原版。
- 实验字段：隐藏人设、隐藏人设触发条件、特殊指令。可以编辑和保存文字。当前原生 NPC 均未开启隐藏人设，改字不会开启，也不代表之后游玩就会触发；特殊指令的实际使用条件尚未验证。
- 个人关系态度开关：单独控制，不会因为修改态度文本而自动打开。态度文本不改变好感度、道侣身份，也不会新增游戏事件。
- 全局提示词：23 个原有模板，包括世界观、任务、通用要求、关系描述和输出格式，不代表覆盖游戏内全部提示词。保存或导入时检查占位变量；不支持调整游戏内部的拼接顺序。输出格式的正文也参与游戏解析，保留变量不等于格式一定正确。
- 预设：导出全部自定义配置与超时值（含当前草稿）；导入先显示差异，确认后仅合并到草稿。预设中未列出的项目保留当前值，不会把整套配置重置为原版。预设不包含模型密钥、聊天记录、存档或本机目录。编辑器自己的预设格式暂不兼容 SillyTavern PNG / JSON 角色卡。
- 回复超时：30—1800 秒，保留 3 / 5 / 10 分钟快捷选择。

游戏内自定义模型若单独设置了大于 0 的超时，会优先使用该值。等待时间与编辑器设置不符时，请先检查游戏内 AI 设置。

模型参数、世界书、记忆管理和本地转发仍是后续功能，目前没有实际编辑能力。

## 使用

1. 工坊订阅下载完成后，打开对应 Steam 库的 `steamapps\workshop\content\4209920\3808285511`，双击 `WorldApart.AI.Editor.exe`。也可运行解压包中的同名程序。编辑器需要手动打开，游戏不会自动启动它。若未自动找到游戏，在“安装与备份”选择游戏目录中的 `WorldApart.exe`。
2. 在“人物”里选择卡片，从字段下拉框选择要修改的内容。修改留在草稿中，不会即时写入游戏。
3. 点底部“查看更改”检查差异。也可在“安装与备份”导出当前预设留存。
4. 完整退出游戏后，点“保存并启用”。然后重新启动游戏，游戏才会重新加载表补丁。

已有聊天记录和记忆不会清除。同配置 ID 的角色会共用修改，不提供存档角色实例隔离。模型是否遵循提示词还取决于模型本身。

已有对话可能保留旧任务提示词。0.3.0 的实测中，从“话题闲聊”结束话题后，新一轮普通闲聊才采用修改后的 `task.chat` 模板。修改模板不代表当前交谈模式会自动切换。

隐藏人设需要游戏先开启对应角色的开关，再判断解锁和启用状态。当前原生 NPC 的该开关均为关闭，编辑器修改文字不会开启它。“特殊指令”是游戏原有字段，其实际使用条件尚未验证，不应视为每次聊天都会发送的指令。

快捷键：`Ctrl+S` 保存，`Ctrl+F` 搜索人物。关闭有草稿的窗口会询问是否放弃。

“撤销此项修改”回到上次保存值；“恢复此字段原版”恢复当前语言字段，仍需保存。导出的“预设”可以导入；旧的“草稿差异 JSON”是检查记录，不能作为预设导入。

## 文件、备份与停用

编辑器继续使用 `local.ai-timeout` Mod ID，接续之前的超时与人物风格设置。补丁目录：

`%USERPROFILE%\AppData\LocalLow\Nuverse\WorldApart\Mods\local.ai-timeout`

保存会写入超时、人物人设、人物背景和全局提示词表补丁，并备份原有文件及 Mod 启用记录。备份在该目录的 `editor-backups` 内。检测到外部工具修改了补丁时停止保存，避免覆盖；可先导出预设，再点“放弃更改”重读磁盘，之后导入预设重新检查。

“安装与备份 → 禁用配置”停用整个编辑器补丁，保留文件，也不移除其他 Mod。停用后同样需要重启游戏。只关闭编辑器或取消工坊订阅，不会停用已保存的设置。

不要同时用旧超时脚本或多份编辑器修改配置。

## 验证范围

本版支持游戏 0.35.7370692（Steam build 25913100）。旧游戏 0.34 / 0.33 请使用编辑器 0.3.0。未识别的游戏版本会禁止保存。

0.3.1 在游戏 0.35.7370692 中完成了导入、保存启用和苏倾盏交谈实测。新增人物背景、原有说话风格，以及修改后的“本轮关系交互”模板均进入本轮实际模型输入；模板变量也正常替换。本地模型约 33 秒后回复，游戏正常显示，没有在 30 秒提前断开。这是一轮交谈的结果，不代表全部模板或超时截止边界均已验证。

0.3.0 在游戏 0.34.7343955 中实测了人物卡片选人、背景编辑、预设导入、保存启用和四轮交谈。模型请求中确认了自定义说话风格、人物背景、亲密阶段 1 的个人态度和新普通闲聊模板。四次回复约耗时 59、40、30、81 秒，游戏均正常显示；未精确测试 180 秒截止边界。

普通闲聊模板的修改只在新生成的对应任务提示中出现，旧聊天保留的提示不会自动全部重写。文本进入请求不代表模型一定遵循；当时使用的模型没有遵守全部措辞要求。

编辑器的数据测试覆盖跨表保存、失败回滚、外部修改冲突、未编辑字段保留、模板变量与预设校验。未逐一实测所有 NPC、语言和模板；隐藏人设激活、特殊指令、其他关系阶段、道侣态度以及不同系统显示缩放仍未验证。公开验证范围见 `docs/compatibility.md`。
