# 不问凡尘 · AI 编辑器

一个在游戏外运行的 Windows 桌面工具，用来调整《不问凡尘》的 AI 对话。你可以改人物背景和提示词，也可以启动本地代理，查看游戏实际发给模型的内容，再用世界书按条件补充设定。

打开编辑器后，首先看到的是**请求工作台**。只想修改人物或延长回复等待时间，直接用左侧的“人物”“全局提示词”“回复设置”即可，不需要启动代理。

当前发布版为 **0.4.2**，支持游戏 **0.38.7394395** 和 **0.35.7370692**。本分支的工作台首页与局域网 HTTP 授权改动尚未发布到工坊；已安装的 0.4.2 不包含这些改动。旧游戏 0.34 / 0.33 请使用编辑器 0.3.0；未识别的版本会禁止保存游戏补丁。各版本的实测范围见[兼容记录](docs/compatibility.md)。

## 打开编辑器

工坊订阅下载完成后，在对应 Steam 库中打开：

```text
steamapps\workshop\content\4209920\3808285511
```

双击 `WorldApart.AI.Editor.exe`；解压包也是运行这个文件。它不会从游戏内的工坊页面自动启动，普通使用不需要 Python、Node.js 或额外 Mod 加载器。若未找到游戏，在“安装与备份”中选择游戏目录里的 `WorldApart.exe`。

## 连接模型，开始使用工作台

1. 在“请求工作台 → 本地代理”填写原来用在游戏中的**模型服务地址**。例如，同一台电脑上的 LM Studio 通常是 `http://127.0.0.1:1234/v1`；公网服务请使用 HTTPS。
2. 点击“启动代理”，设置会一并保存。编辑器默认只在本机的 `http://127.0.0.1:18181/v1` 监听。
3. 将页面里的**游戏连接地址**复制到游戏的自定义模型服务地址。模型名和 API 密钥仍填在游戏中，编辑器不会替你修改游戏设置。
4. 想看模型收到了什么，勾选“记录请求正文”并保存，再在游戏中交谈。“请求记录”可查看原始消息、实际转发内容、JSON 和世界书处理结果，也可搜索、复制。

使用代理期间要保持编辑器打开。停用时，先把游戏地址改回原模型服务地址，再停止代理或关闭编辑器。

### LM Studio 在局域网的另一台电脑上

填写那台电脑的实际地址，例如 `http://192.168.0.235:1234/v1`。确认页面显示的 IP 和端口属于你自己的模型服务，再勾选“我信任此局域网 HTTP 服务”，启动代理。

HTTP 不加密，游戏对话和传来的 API 密钥会以明文发送。这个选项只适用于你信任的网络和服务，且只授权当前 **IP 与端口**。可用范围是 `192.168.x.x`、`10.x.x.x`、`172.16.x.x` 至 `172.31.x.x` 的标准 IPv4 地址；不接受内网域名、IPv6 或其他网段作为 HTTP 授权目标，不会自动跟随上游重定向。

编辑模型地址会清除授权勾选，即使随后改回原地址也要重新确认。取消勾选后点击“保存代理设置”即可撤销；保存地址、端口或授权的改动会停止代理并中断当前请求，需要重新启动。模型电脑仍需自行运行并开放对应服务，编辑器不会修改防火墙或系统网络设置。**此分支尚未完成 Windows 界面及真实局域网 LM Studio 的实机验证。**

### 请求记录与等待时间

记录默认关闭；开启后只在本次运行的内存中保留最近最多 20 条、合计 800 万字符的请求正文。取消记录并保存、清空记录或退出编辑器都会清除正文。Authorization 请求头和模型回复正文不记录；请求本身可能包含私人聊天，分享前请检查。

代理支持 OpenAI 兼容的 Chat Completions 普通响应、SSE 流式响应及模型列表接口。上游失败会返回错误，不自动重试。查看器展示经过代理的内容，不包含模型服务后来套用的聊天模板。

代理等待时间和游戏回复超时分别设置，先到期的一方会结束等待。游戏自定义模型若设置了大于 0 的超时，会优先使用那个值；只延长代理等待时间不会延长游戏超时。

## 修改人物和游戏提示词

1. 在“人物”中按姓名、称号或配置 ID 搜索，选中卡片后选择字段和语言。也可以在“全局提示词”修改模板，或在“回复设置”调整 30—1800 秒的等待时间。
2. 修改先留在草稿里。点底部“查看更改”检查差异；需要留存时，可在“安装与备份”导出预设。
3. **完整退出游戏后**，点击“保存游戏补丁”，再重新启动游戏。只关闭编辑器或取消工坊订阅，不会撤销已保存的设置。

人物库有 1,591 个配置：1,156 个可编辑人设与背景，435 个只开放背景。这是游戏配置目录，不是存档角色清单；同配置 ID 的角色共用修改。存档改名、动态名字和其他 Mod 新增人物可能搜不到，不能用名字相近的配置代替。

人物可编辑的内容取决于原表，包括背景、说话风格和已有关系态度阶段。“仅背景”人物不会补建人设记录或缺失阶段。个人关系态度开关需要单独打开；修改态度文字不会改变好感度、道侣身份或新增事件。

全局提示词提供 23 个原有模板，支持简体中文、繁体中文和英文。请保留占位变量；输出格式还参与游戏解析，不宜随意改写结构。隐藏人设、触发条件和特殊指令仍是实验字段：修改文字不会开启原生 NPC 的隐藏人设开关，实际触发未验证。

“撤销此项修改”回到上次保存值；“恢复此字段原版”恢复当前语言字段，仍需保存。`Ctrl+S` 保存游戏补丁，`Ctrl+F` 搜索人物。

### 预设和人物方案

**预设**适合备份或分享一组改动，包含全部自定义游戏补丁设置、超时和当前草稿。导入时先看差异，确认后合并到草稿；预设没有列出的项目保留当前值。它不包含模型密钥、聊天、存档、本机目录，也不包含工作台资料库。旧的“草稿差异 JSON”只能查看，不能作为预设导入。

**人物方案**适合为同一人物保存几个版本。在人物详情点击“人物方案…”，可保存此人物全部开放字段与语言，包括当前草稿。应用时会替换该人物的完整可编辑设定，保留其他人物和全局配置；随后仍要保存游戏补丁并重启游戏。方案按配置 ID 绑定，不切换聊天记忆；“设定预览”也只显示本地草稿。

目前不支持 SillyTavern 角色卡、模型采样参数或记忆管理。

## 用世界书补充设定

在“请求工作台 → 世界书”新建条目，写入正文和关键词，启用并保存。下一条经过代理的请求会使用新规则，不需要重启游戏。

- 关键词用逗号或换行分隔，忽略大小写、按子串匹配；可要求任意命中或全部命中，范围可选最后一条或最近四条玩家消息。
- 可加“系统文本须包含”条件，在 system / developer 消息中查找指定文字。它要与关键词条件同时满足；名字可能出现在历史或说明中，不能据此准确识别人物。
- “不要求关键词”仍检查系统文本条件；两者都不限制时，每次请求都会加入条目。
- 优先级较大的条目先加入，同级按条目 ID 排序。字符预算含标题和分隔符，放不下就整条跳过；预算 0 表示不插入。这里按字符计数，不按 token。

命中的条目合并为一条 system 消息，放在最后一组用户 / 工具消息之前；没有命中则原样转发。“试匹配…”可用粘贴的请求 JSON 检查草稿，不连接模型。

世界书不读取地点、好感度或任务状态，也不修改存档；暂不支持递归激活和 SillyTavern 世界书导入。不同模型对新增 system 消息的处理不同，建议从少量条目开始。

## 修改没有生效？

先确认已保存补丁并完整重启游戏，再结束当前话题，发起新一轮普通闲聊。旧任务提示、聊天历史和长期记忆不会自动清除，可能继续影响结果。

在“安装与备份”点“检查生效…”，或在人物详情点“修改没有生效？”，可以检查草稿、启用记录、磁盘改动和启动时间。这个检查只读，不会清除聊天或自动开启记录；检查通过也不能单独证明游戏已加载补丁。

仍不确定时，用请求工作台记录一轮对话，搜索你改过的独特短句。没进入请求，继续检查配置加载和交谈模式；已进入请求但回复没遵循，则还要考虑历史与模型表现。不要为排查直接删除存档。

芊儿、念乔、沈桐桐、柳婵在当前目录里只开放背景；赤遥部分原字段为空，也没有原配道侣阶段。“沈凤”尚未在基础表中定位。反馈人物问题时请附原名、称号、地点和游戏版本；程序打不开时请附错误文字，不要附密钥、完整聊天或存档。语音 Mod 尚未逐项验证兼容性。

## 文件、备份与停用

游戏补丁沿用 `local.ai-timeout`，保存位置是：

```text
%USERPROFILE%\AppData\LocalLow\Nuverse\WorldApart\Mods\local.ai-timeout
```

保存时会备份原文件和 Mod 启用记录，放在该目录的 `editor-backups` 中。如果检测到其他工具改过补丁，编辑器会停止保存。可以先导出预设，再点“放弃更改”重读磁盘，最后导入预设重新检查。不要同时用旧超时脚本或多份编辑器写入配置。

“安装与备份 → 禁用配置”会停用整个编辑器游戏补丁，保留文件和其他 Mod，重启游戏后生效。它不会停止代理或停用世界书。

人物方案、世界书、代理设置及局域网授权保存在：

```text
%LOCALAPPDATA%\WorldApart.AI.Editor\studio.json
```

保存前会保留上一版 `.bak`。资料库损坏时，可在“本地代理 → 恢复资料库…”恢复备份或重建空库，损坏文件会另存保留。恢复资料库会清除局域网 HTTP 授权，启动前请重新检查地址并勾选。完整备份请同时保存此资料库和游戏补丁目录。
