# 不问凡尘 · AI 编辑器 0.4.2

游戏外 Windows 桌面工具。游戏内创意工坊入口不会打开编辑器；订阅下载后请手动运行，保存游戏补丁时由编辑器写入并启用配置。双击 `WorldApart.AI.Editor.exe` 即可使用，不需要 Python、Node.js 或额外 Mod 加载器。

0.4.2 适配游戏 0.38.7394395（Steam build 26095911），同时保留 0.35.7370692 的版本识别。两版的四张 AI 参考表完全一致，已有超时、人物修改、预设与人物方案可继续使用。本次不增加编辑字段或人物数量。 已在新版游戏中实测柳婵背景进入实际模型输入，约 32 秒后正常收到回复；其他人物未逐一实测。

编辑器提供人物卡片、人物背景与关系态度编辑、23 个全局模板，以及编辑器自己的 JSON 预设。之前保存的超时和说话风格设置会继续使用。隐藏人设、触发条件和特殊指令仍标为实验，实际触发尚未验证。

## 本版功能

- 人物库：1,591 个配置（不含 ID 为 -1 的空白占位项），其中 1,223 个有头像路径。1,156 条标为“人设与背景”，435 条标为“仅背景”。这不是存档中的角色实例清单，也不代表每条配置都可聊天。头像来自游戏，共用头像仍按称号和配置 ID 区分；缺图时显示姓名首字。每页 12 张卡片，支持原表简体名、繁体名、英文名、称号或 ID 搜索，以及“只看自定义与草稿”。进入编辑后左侧为紧凑头像列表，返回时保留搜索、页码和滚动位置。
- 人物编辑：有人设记录的角色可编辑说话风格、人物背景，以及原表已有的亲密度 / 道侣态度阶段；“仅背景”角色只开放人物背景，不补建 AI 人设记录或缺失关系阶段。支持简体中文、繁体中文和英文、原版对照、撤销此项修改和恢复原版。
- 实验字段：隐藏人设、隐藏人设触发条件、特殊指令。可以编辑和保存文字。当前原生 NPC 均未开启隐藏人设，改字不会开启，也不代表之后游玩就会触发；特殊指令的实际使用条件尚未验证。
- 个人关系态度开关：单独控制，不会因为修改态度文本而自动打开。态度文本不改变好感度、道侣身份，也不会新增游戏事件。
- 全局提示词：23 个原有模板，包括世界观、任务、通用要求、关系描述和输出格式，不代表覆盖游戏内全部提示词。保存或导入时检查占位变量；不支持调整游戏内部的拼接顺序。输出格式的正文也参与游戏解析，保留变量不等于格式一定正确。
- 预设：导出全部自定义配置与超时值（含当前草稿）；导入先显示差异，确认后仅合并到草稿。预设中未列出的项目保留当前值，不会把整套配置重置为原版。预设不包含模型密钥、聊天记录、存档或本机目录。编辑器自己的预设格式暂不兼容 SillyTavern PNG / JSON 角色卡。
- 回复超时：30—1800 秒，保留 3 / 5 / 10 分钟快捷选择。

游戏内自定义模型若单独设置了大于 0 的超时，会优先使用该值。等待时间与编辑器设置不符时，请先检查游戏内 AI 设置。

模型采样参数、记忆管理、SillyTavern 角色卡交换仍未开放。

## 使用

1. 工坊订阅下载完成后，打开对应 Steam 库的 `steamapps\workshop\content\4209920\3808285511`，双击 `WorldApart.AI.Editor.exe`。也可运行解压包中的同名程序。编辑器需要手动打开，游戏不会自动启动它。若未自动找到游戏，在“安装与备份”选择游戏目录中的 `WorldApart.exe`。
2. 在“人物”里选择卡片，从字段下拉框选择要修改的内容。修改留在草稿中，不会即时写入游戏。
3. 点底部“查看更改”检查差异。也可在“安装与备份”导出当前预设留存。
4. 完整退出游戏后，点“保存游戏补丁”。然后重新启动游戏，游戏才会重新加载表补丁。

已有聊天记录和记忆不会清除。同配置 ID 的角色会共用修改，不提供存档角色实例隔离。模型是否遵循提示词还取决于模型本身。

已有对话可能保留旧任务提示词。0.3.0 的实测中，从“话题闲聊”结束话题后，新一轮普通闲聊才采用修改后的 `task.chat` 模板。修改模板不代表当前交谈模式会自动切换。

隐藏人设需要游戏先开启对应角色的开关，再判断解锁和启用状态。当前原生 NPC 的该开关均为关闭，编辑器修改文字不会开启它。“特殊指令”是游戏原有字段，其实际使用条件尚未验证，不应视为每次聊天都会发送的指令。

快捷键：`Ctrl+S` 保存游戏补丁，`Ctrl+F` 搜索人物。关闭有草稿的窗口会询问是否放弃。

“撤销此项修改”回到上次保存值；“恢复此字段原版”恢复当前语言字段，仍需保存。导出的“预设”可以导入；旧的“草稿差异 JSON”是检查记录，不能作为预设导入。

## 人物缺失与修改生效排查

在“安装与备份”点“检查生效…”，或从人物详情点“修改没有生效？”。它检查草稿、启用记录、磁盘文件是否被其他程序改动，以及游戏启动时间与补丁最近写入时间。不会修改文件、清除聊天或自动开启请求记录；启用记录和时间检查不能证明游戏已加载配置。

- 芊儿（193401）、念乔（150101）、沈桐桐（194401）、柳婵（110402）已补入目录。当前原表没有对应 AI 人设记录，此版只开放人物背景，支持背景方案和预设。此前遗漏来自目录只遍历人设表。
- 赤遥（191401）的说话风格、隐藏人设等原字段为空，原表未配置道侣阶段。本次没有找到另一条同名基础配置，不能据此断定游戏所有场景都只用这一条配置。
- 当前人设表只有 5 条配置含道侣阶段 4、5。下拉列表按原表显示，缺项不是编辑器判断角色尚未解锁；本版不补建这些阶段。
- “沈凤”尚未在本版基础表名字中定位。存档改名、动态生成名字和其他 Mod 新增人物可能不在目录；反馈时请附原名、称号、地点和游戏版本，不要套用相近名字的配置。

确认保存并完整重启后，可结束当前话题，发起新一轮普通闲聊。旧任务提示、聊天历史和长期记忆仍可能影响结果。需要进一步核对时，在请求工作台记录一轮请求，搜索修改过的独特短句：未进入请求时检查配置加载与交谈模式；已进入请求而回复未遵循时，再检查历史影响和模型表现。不要为排查直接删除存档。

游戏内工坊显示不能读取时，先按上述路径手动运行编辑器。启动说明不能代替对具体错误的诊断；若程序本身打不开，请提供错误文字。语音 Mod 是否兼容还需要具体名称和链接，目前没有逐项验证。

## 人物方案

进入人物卡片后点“人物方案…”，可以把此人物实际开放的全部字段和语言（有人设记录时也包含个人态度开关）保存为一份方案，包含尚未保存的草稿。建议先保存原设，再制作其他版本。

选中方案会显示与当前草稿的逐项差异。“应用到此人物草稿”替换这个人物的完整可编辑设定，保留其他人物、全局模板和超时。应用后仍需退出游戏、保存游戏补丁并重新启动。方案按配置 ID 绑定；参考数据不兼容时拒绝应用。它不会切换聊天记忆，也不是存档角色实例管理。

“设定预览”只显示当前人物的本地草稿，不包含游戏运行中的任务、关系状态和聊天历史。

## 请求工作台

这部分按需使用。只编辑游戏补丁或人物方案时，不需要启动代理。

1. 在“本地代理”填写原来的模型服务地址，例如 LM Studio 的 `http://127.0.0.1:1234/v1`。远程服务使用 HTTPS。
2. 保存设置，启动代理。默认监听地址为 `http://127.0.0.1:18181/v1`，仅本机可访问。
3. 把这个代理地址填入游戏自定义模型服务地址。模型名和 API 密钥仍在游戏中填写；编辑器不会自动修改游戏连接设置。
4. 若需要查看请求，勾选“记录请求正文”并保存，再在游戏中交谈。“请求记录”可阅读原始请求、实际转发内容、原始 JSON 和世界书处理结果，并查找、复制内容。
5. 使用代理期间保持编辑器打开。停用时先将游戏地址改回原模型服务地址，再停止代理或关闭编辑器。

记录默认关闭。开启后只在本次运行的内存中保留最近最多 20 条、合计 800 万字符的请求正文；关闭记录并保存、清空记录或退出编辑器会清除正文。Authorization 请求头和模型回复正文不记录。请求可能包含人物设定与私人聊天，复制出去前请自行检查。

查看器展示游戏发出的消息及代理转发结果，不推断每段文字在游戏内部的来源，也不展示模型服务后续套用的聊天模板。代理支持 OpenAI 兼容的 Chat Completions 普通响应和 SSE 流式响应，以及模型列表接口。其他接口、供应商专用格式尚不支持。上游请求失败会返回错误，不自动重试。

代理等待时间和游戏回复超时分别设置；谁先到期，谁先结束等待。单独增大代理等待时间不会延长游戏自己的超时。

## 世界书与条件提示词

在“请求工作台 → 世界书”新建条目，填写正文并启用，保存后用于下一条代理请求，无需重启游戏。正在处理的请求仍使用开始时的规则。

- 关键词以逗号或换行分隔，忽略大小写，按子串匹配；可选任意命中或全部命中。
- 匹配范围可选最后一条玩家消息或最近四条玩家消息。
- 可增加系统文本条件，在 system / developer 消息中查找指定文字。它与关键词条件同时成立才触发；名字可能出现在历史或其他说明中，因此不等于准确的人物身份识别。
- “不要求关键词”仍检查系统文本条件；两者都不限制时，每次请求都会加入该条目。
- 优先级较大的条目先加入，同级按条目 ID 排序。字符预算包含标题和分隔符，放不下时整条跳过，0 表示不插入。当前按字符控制，不按模型 token 计数。
- 命中内容合并为一条 system 消息，放在最后一组用户 / 工具消息之前，保留原消息顺序。没有命中时原样转发请求。

“试匹配…”使用当前世界书草稿检查粘贴的 Chat Completions JSON，不连接模型。真实请求中的处理结果可以查看哪些条目加入或跳过，以及实际加入的正文。

这版不读取游戏地点、好感度或任务状态，不修改游戏存档，不支持递归激活或 SillyTavern 世界书格式导入。不同模型对新增 system 消息的处理可能不同，建议先用少量条目验证。

## 文件、备份与停用

编辑器继续使用 `local.ai-timeout` Mod ID，接续之前的超时与人物风格设置。补丁目录：

`%USERPROFILE%\AppData\LocalLow\Nuverse\WorldApart\Mods\local.ai-timeout`

保存会写入超时、人物人设、人物背景和全局提示词表补丁，并备份原有文件及 Mod 启用记录。备份在该目录的 `editor-backups` 内。检测到外部工具修改了补丁时停止保存，避免覆盖；可先导出预设，再点“放弃更改”重读磁盘，之后导入预设重新检查。

“安装与备份 → 禁用配置”停用整个编辑器补丁，保留文件，也不移除其他 Mod。停用后同样需要重启游戏。只关闭编辑器或取消工坊订阅，不会停用已保存的设置。

人物方案、世界书和代理设置单独存放在 `%LOCALAPPDATA%\WorldApart.AI.Editor\studio.json`，保存前保留上一版 `.bak`。资料库损坏时不会自动覆盖，可在“本地代理 → 恢复资料库…”选择恢复备份或重建空库，当前损坏文件另存保留。完整备份时请同时保存此资料库和游戏补丁目录。现有“导出预设”只导出游戏补丁设置，不包含工作台资料库。

禁用游戏补丁不会停止代理或停用世界书。关闭编辑器也不会停用已写入的游戏补丁。

不要同时用旧超时脚本或多份编辑器修改配置。

## 验证范围

本版支持游戏 0.35.7370692（Steam build 25913100）。旧游戏 0.34 / 0.33 请使用编辑器 0.3.0。未识别的游戏版本会禁止保存游戏补丁。

0.4.0 在游戏 0.35.7370692 中完成了人物方案保存、切换和两轮经本地代理的交谈。第一轮约 23 秒，人物方案与命中的世界书进入实际请求，游戏正常显示回复；第二轮约 28 秒，关键词未命中，原始与转发 JSON 完全一致，游戏仍正常收到回复。真实游戏验证使用本机 LM Studio，流式转发另用本地测试服务验证；未逐一实测远程供应商或精确超时截止边界。

0.3.1 在游戏 0.35.7370692 中完成了导入、保存启用和苏倾盏交谈实测。新增人物背景、原有说话风格，以及修改后的“本轮关系交互”模板均进入本轮实际模型输入；模板变量也正常替换。本地模型约 33 秒后回复，游戏正常显示，没有在 30 秒提前断开。这是一轮交谈的结果，不代表全部模板或超时截止边界均已验证。

0.3.0 在游戏 0.34.7343955 中实测了人物卡片选人、背景编辑、预设导入、保存启用和四轮交谈。模型请求中确认了自定义说话风格、人物背景、亲密阶段 1 的个人态度和新普通闲聊模板。四次回复约耗时 59、40、30、81 秒，游戏均正常显示；未精确测试 180 秒截止边界。

普通闲聊模板的修改只在新生成的对应任务提示中出现，旧聊天保留的提示不会自动全部重写。文本进入请求不代表模型一定遵循；当时使用的模型没有遵守全部措辞要求。

编辑器的数据测试覆盖跨表保存、失败回滚、外部修改冲突、未编辑字段保留、模板变量与预设校验。未逐一实测所有 NPC、语言和模板；隐藏人设激活、特殊指令、其他关系阶段、道侣态度以及不同系统显示缩放仍未验证。公开验证范围见 `docs/compatibility.md`。
